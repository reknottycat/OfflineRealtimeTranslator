# 国内优先模型下载（v3.6）

## 修复的问题

v3.5 的默认来源是 HuggingFace，自动模式也先访问 HF；“ModelScope”在模型目录中返回空链接，实际只允许手填 URL。中国网络无法完成 HF 文件连接时，设置页无法直接使用魔搭上已经存在的相同权重。

本次同时修复来源目录、旧设置迁移、真实 HTTP 失败切换及大文件断点下载。原有三款翻译权重的 SHA-256、文件名、安装目录和推理后端保持原工件身份。

## 来源规则

默认顺序为 ModelScope 固定版本 resolve → ModelScope API → HF Mirror → `gh-proxy.org` → `ghproxy.imciel.com` → `gh-proxy.com` → HuggingFace。所有代理前缀后拼接完整、固定 revision 的 HF HTTPS URL。

Gemma 4 与 HY-MT2 的 ModelScope 工件已核对精确字节数、摘要和非零范围下载；LMT 未找到同哈希 GGUF，因此不伪造魔搭链接。ModelScope 的两个入口可能共享 CDN；`.org/.com` 在本次观测中也共享故障路径。来源证据与完整地址见 [核验说明](model-downloads/README.md)。

三个代理按用户提供的名单纳入候选，不标为始终可用。本次云端对 `.org/.com` 取得的是 195 字节 HTML（甚至返回 206），对 `imciel` 取得 403；实际客户端根据响应拒绝并切换。排除用户已确认失效的四个代理。

界面选择某个来源表示“优先”，仍保留其余备用来源。自定义 URL 单独保存，必须是无内嵌登录凭据的 HTTPS 文件直链。旧版未配置来源或默认 HF 的用户会一次性迁移为自动模式；旧 ModelScope 选项里已保存的自定义 URL 保留到独立的自定义模式。

## 分块和断点

- 每块 4 MiB，默认同时下载 4 块，手机端不默认开启 14–28 个连接。
- 每块最多尝试 8 次；错误状态、错误格式或大小不匹配的源被拒绝，临时连接失败的源短暂冷却后可重试。
- 每次分块响应必须为 206，起点、终点、总长度及响应字节数必须与请求和模型目录一致。HTML/JSON 等错误正文不能成为已完成分块。
- 每块完整收到后按偏移写入同一 `.part` 文件并执行 `fsync`，再原子更新 `.chunks.done`。记录包含模型总 SHA-256、总大小、块大小及每个完成块的摘要。
- 重启后重算已记录分块的摘要，只保留完整且内容未变化的块。预分配文件大小不会被当作下载完成。
- 暂停、Activity 销毁及 coroutine 取消会关闭活动 HTTP 连接，停止并等待所有 worker；用户回到设置点击继续恢复。
- 服务端忽略 Range 返回 200 时，不把整个文件写进某个分块；没有合适的分块来源时安全回退到顺序下载。
- 完成所有块后计算整文件 SHA-256。块摘要只用于本地断点一致性，不替代整文件真实性校验。整文件校验失败后清理受污染分块，逐源做有界的干净重试。
- 仅在全文件校验通过后，原子替换安装路径并更新安装凭据；下载失败不会覆盖此前安装的模型。

HTTPS 请求本身就是连通性检查，不使用 ICMP ping 或网站首页作为文件可下载的证明。连接超时 12 秒、读取无数据超时 20 秒，重定向建连有独立 45 秒预算和有限跳数。下载进度显示来源、当前分块、尝试次数及切换原因。

## 验证与实际边界

来源目录测试覆盖国内优先、精确 ModelScope revision、LMT 缺少魔搭时仍有备用来源、代理完整 URL、手动优先和自定义 URL 校验。生产下载器用本地 HTTP 服务和可注入连接进行 Range、错误 HTML、短读、无 Range、恢复、损坏块、最终摘要失败及并发取消测试。

构建命令：

```bash
./gradlew --no-daemon --max-workers=4 :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

预发布流程对推送的确切 commit 构建、测试、lint、验签；使用新 tag，保留 APK、摘要、签名和验证报告，并在下载分支追加新目录。不会用旧版本 CI 工件冒充本次构建。

实际中国手机运营商网络、速度、后台长时间运行和端到端麦克风/字幕仍需要设备验收。本实现仍是设置页前台下载，不是后台服务；退出后需要回到设置点击继续。语音模型的单独部署流程未纳入此次翻译模型下载器改动。Android 真机推理和翻译质量不由下载器测试证明。
